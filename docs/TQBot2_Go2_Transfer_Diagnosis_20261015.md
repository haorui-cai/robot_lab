# TQBot2 与 Go2：相同训练参数为何不等效（2026-10-15）

**后续证据更新：**用户指出 Pi 的旧 TQBot2 RLWalk 已能迈步。核对后确认旧版也具有同样的前后腿转轴方向、joint_mirror 公式及 −0.05 权重，并同样没有目标步频奖励。因此下文的几何先验冲突不能作为新旧 TQBot2 行走退化的主要差异解释。更直接的差异是学习继承历史、限位收紧的时机、接触对象/奖励、训练控制参数与部署处理。详见 [Pi RLWalk 与本次训练对照](TQBot2_Pi_RLWalk_vs_Current_20261015.md)。

本次对象为 StandardWalk：TQBot2 从隐式 PD 的 model_1500 续训、放宽限位并修订足端奖励的实验；Go2 为 2026-10-14 14:50 开始的从零训练。冻结 env.yaml、agent.yaml、URDF 和奖励源码是事实来源。未运行新的训练或仿真。

## 1. 同迭代日志说明了什么

下表均取第 2500–2699 轮，200 个原始 TensorBoard 标量算术平均。Episode_Reward 是日志中已加权、按回合时长口径归一的项；Train/mean_reward 是回合回报，两者不能直接逐项相加比较。

| 指标 | TQBot2 当前续训 | Go2 从零训练 |
|---|---:|---:|
| 线速度跟踪奖励 | 0.892 | 1.341 |
| 平面速度误差日志指标 | 1.300 | 1.053 |
| 地形平均等级 | 1.478 | 4.028 |
| 关节加速度成本 | −0.346 | −0.796 |
| 姿态偏离成本 | −0.578 | −1.087 |
| 动作变化成本 | −0.668 | −0.623 |
| 关节限位成本 | −0.066 | −0.026 |
| 步态奖励 | 0.375 | 0.427 |
| 腾空时间奖励 | −0.0162 | −0.0176 |
| Train/mean_reward | 63.12 | 52.69 |

TQBot2 总回报更高，但跟踪更差。两者回合长度、地形分布、足高/滑移函数及物理系统不同，因此这不证明贴地行为在同一个 MDP 中一定优于行走。它直接说明不能把跨机器人总回报作为行走质量的排序。当前 TQBot2 的加速度成本也已低于 Go2，旧显式 DC 训练的高加速度现象不能继续当作当前主要原因。负的腾空项在 Go2 同样存在，不能凭这一项独立解释成败。

PPO 的网络、优化与 rollout 配置基本一致。当前两个续训 agent.yaml 中的算法差别仅学习率最后几位浮点误差；历史从零起点和训练中实际自适应学习率不能据此视为完全相同。

## 2. 新确认：关节镜像先验与 TQBot2 几何不匹配

两个实验冻结的 joint_mirror 函数完全相同，对 FR/RL 与 FL/RR 两对关节直接计算角度差平方，权重 −0.05。它鼓励对角腿对应关节取相同角度。

但冻结 URDF 中 TQBot2 前腿 thigh/calf 轴为 +Y，后腿为 −Y；Go2 前后腿均为 +Y。使用实际站立参考、完整 URDF 前向运动学和 ±1e−6 rad 中心差分，得到：

| 站立附近的导数，m/rad | TQBot2 前腿 | TQBot2 后腿 | Go2 前腿 | Go2 后腿 |
|---|---:|---:|---:|---:|
| ∂足端 x / ∂大腿角 | −0.2500 | +0.2500 | −0.3113 | −0.3113 |
| ∂足端 x / ∂小腿角 | −0.1016 | +0.1016 | −0.1629 | −0.1629 |

例如，局部线性化下让足端沿机身 +X 移动 2 cm、保持高度，TQBot2 前腿需要大腿/小腿变化约 [−0.0704, −0.0236] rad，后腿需要 [+0.0704, +0.0236]；Go2 前后腿均约 [−0.0606, −0.00688] rad。

因此 TQBot2 的“对角腿同接触相位”和“对角腿相同关节角”不是同一个正确的运动先验。前者可用于 trot，后者会对同向足端运动产生冲突。该验证是运动学事实，不是学习消融；权重较小、当前平均成本约 −0.0089，不足以认定其为主要根因。不能简单把所有后腿角度取负：摆动高度、非线性几何与站立参考也需要处理。更可靠的候选是取消该关节角约束，或在明确坐标与参考下约束足端运动。

## 3. 控制与动作探索也不等效

当前 TQBot2 使用 implicit PD，Kp/Kd=14/0.6，髋/大腿力矩上限 21.33 Nm、小腿 31.995 Nm，关节静/动摩擦 0.4/0.4 Nm；Go2 使用显式 DCMotor，25/0.5、23.5 Nm、摩擦 0。相同 action scale 并不产生相同力矩响应、足端运动或训练样本。

TQBot2 大腿零位 0.80 rad，当前硬/软下限为 0.45/0.60 rad；Go2 前腿硬下限 −1.5708、后腿 −0.5236 rad。对 TQBot2，朝下限方向的探索余量明显更小。旧版本下限曾为 0.60/0.73，不能混用为当前值。当前良好平台回放里实际关节未逼近硬限位，因此探索限制和“执行时卡死在限位”应分别验证。

有限刚度 PD 的位置误差用于产生负载力矩；位置目标跨度很大，并不自动说明已生成可实现的摆腿轨迹，也不等于电机额定力矩不足。既有平台片段小腿估算力矩未饱和，但 implicit applied_torque 仅为估算值。

## 4. 已观察到的贴地模式与奖励漏洞

已有 model_2500 的平台片段中，足×控制步接触占比 99.917%；小腿实际 P5–P95 跨度约 2.47°–7.77°，目标跨度约 33.4°–70.7°。这支持控制输出主要用于承重而未形成有效卸载/摆动。全 24 场景接触占比为 96.56%，不能把单个平台数值当作全部训练分布。

当前足高项只惩罚已经离地的脚，四脚常驻地面时为零；步态公式对长期四足接触仍可给 0.318/0.5；腾空项在落地时计算 0.1×(air_time−0.5)，短摆动会扣分。以上是当前机制，不是足高筛选造成原始小碎步的证据：model_1500 在修改前已经有该行为。Go2 共享部分机制且仍能学会走路，说明漏洞与机器人动力学、探索过程相互作用，不能单凭共享漏洞解释机器人之间的差异。

行为原始数据和历史复测见 [小步诊断](TQBot2_Small_Steps_Diagnosis_20261015.md)。旧显式执行器的不稳定范围见 [训练因果复核](TQBot2_Walk_Training_Causality_20261014.md)。

## 5. 最有区分力的下一步

1. 先做固定机身卸载与承重转卸载的短轨迹试验，确认名义/随机化控制下可实现摆腿。用实际足端轨迹和接触状态判断，不用单看位置目标或总奖励。
2. 建立平地、直立出生、固定低速的最小训练基线；这是能力门槛检查，不是单变量因果结论。成功后逐项恢复随机化、恢复任务和地形难度。
3. 在同一基线和配对随机种子下，分别比较原配置、仅移除 joint_mirror、仅修订接触/摆动激励。多个随机种子和一致的确定性评估可区分结构性问题与偶然收敛。不要多项同时改变后声称定位单因。

优先检查机器人几何相关先验、有效卸载/摆动的学习信号和控制实现能力；当前证据不足以把问题归为 PPO 超参数、单纯力矩不足或单纯训练轮数不足。

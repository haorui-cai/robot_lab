# TQBot2 小腿振荡根因定位（2026-10-14）

**范围说明：**本文的“根因”仅指所测固定目标振荡的机制，不代表已经证明行走训练失败的根因。尚无只改变物理步长、其余训练条件一致的从零训练消融。用户指出站立观察不到抖动后，已将学习问题独立复核，见 [训练因果复核](TQBot2_Walk_Training_Causality_20261014.md)。

已用直接仿真干预定位：当前模型小腿惯量较小，Kp14/Kd0.6 的显式DC反馈在5ms积分周期下存在离散不稳定。无重力、无地面接触、固定机身且只给小腿初始角度0.05rad扰动时，关节速度最终每步在+20.06/-20.06rad/s之间交替，即100Hz、周期两个物理步的数值极限环。新旧摩擦API切换还曾掩盖这项不稳定：仅将新参数置0并没有关闭旧摩擦。

这定位的是可复现的动力学异常，尚未证明它导致3000轮训练失败；修正积分稳定性后仍需受控的从零训练验证其学习效果。

## 排除两层PD及接触原因

实测 PhysX 所有DOF刚度=0、阻尼=0；_has_implicit_actuators=False，两个组都是DCMotor。IsaacLab的显式路径只写力矩，清空关节位置/速度驱动；增益随机化对显式模型不写回引擎PD。因此没有叠加第二层PD。

32环境、seed42、每组6秒，统计后3秒；保持14/0.6且关闭增益随机化，质量/COM/材料仍沿训练抽样；平地基线固定默认目标，无推扰与外力、无观测噪声。单项改变：

| 平地固定目标干预 | 关节速度RMS rad/s | 加速度RMS rad/s² |
|---|---:|---:|
| 基线 | 3.732 | 1397.2 |
| 关闭自碰撞 | 3.708 | 1387.3 |
| 速度求解迭代0→4 | 3.878 | 1469.4 |
| 小腿自身COM惯量张量×3（诊断） | 0.946 | 31.6 |
| 小腿armature加0.003kg·m²（诊断） | 0.477 | 76.5 |
| 仅小腿Kd 0.6→0.1（诊断） | 1.646 | 45.2 |

四个calf关节的物理子步加速度RMS分别约2416/2372/2412/2378rad/s²，是主要异常来源。上述惯量与armature是干预，未写入URDF或训练默认，不能把任意增加惯量当作实际机器人参数。

## 无接触复现与摩擦API的更正

将机身固定在2m，关闭所有身体重力，四个小腿从默认角度扰动+0.05rad，其余关节默认；物理步长仍5ms，无地面接触。

| 配置 | 关节速度RMS rad/s | 加速度RMS rad/s² |
|---|---:|---:|
| TQBot2 原模型、新静摩擦0.2、旧系数0.2 | 11.760 | 4704.0 |
| 同模型，只有新三项摩擦全0、旧系数仍0.2 | 约8.6e−7 | 约1.0e−6 |
| 同模型，新旧摩擦全部0 | 11.760 | 4704.0 |
| 新静/动摩擦均0.2、旧系数仍0.2 | 5.487 | 2194.8 |
| 只将小腿Kd降至0.1，原摩擦保持 | 接近0 | 约0.1 |
| TQBot2 foot合并回calf，原摩擦保持 | 11.712 | 4684.9 |
| Go2，同样14/0.6、新静摩擦0.2，悬空 | 约0.00052 | 约0.186 |

原始TQBot2模型的底层旧摩擦系数是0.2，新API三项为[静摩擦力矩0.2、动摩擦力矩0、黏性系数0]。新三项全部置0后，旧系数仍0.2。新旧全部置0则重新出现与基线相同的极限环。这直接证明早期的“friction_zero稳定”实际上包含旧摩擦模型的作用，不能解读为完全无摩擦稳定，也不能将新静摩擦0.2单独定为根本原因。

新版新API与旧系数的模型分支问题也有[NVIDIA PhysX API记录](https://github.com/NVIDIA-Omniverse/PhysX/issues/498)。该外部记录只是辅助解释，本报告结论由本机同时读取新旧数值和对照验证支持。

固定foot与合并foot都复现，零接触下也复现；关闭自碰撞和增大速度求解迭代均无效。因此独立foot的碰撞设置、地面摩擦、两层PD不能解释这组异常。

## 低惯量与显式积分的关系

独立按当前URDF的calf质心惯量、平行轴项和foot质量/位置计算，父关节固定时膝轴转动惯量：TQBot2约0.001457kg·m²，Go2约0.004966kg·m²，TQBot2只有29.3%。TQBot2短小腿为120g、foot15g；Go2小腿154g、foot40g。实际自由机身、质量/COM随机化和关节耦合下，最初基线的膝关节等效惯量约0.00118kg·m²；新无接触检查的实际范围约0.00101–0.00142。

对于单轴、无摩擦、父关节固定的简化半隐式Euler模型，显式PD的稳定条件为 Kp·h²+2·Kd·h<4J。名义14/0.6代入TQBot2上述URDF惯量，临界h约4.61ms；Go2为14.20ms。这是局部简化解释，不能当作完整PhysX多体/摩擦/接触系统的精确稳定界。降低Kd、增加惯量、缩短h的实测干预方向与此一致。旧20/0.5以及宽增益/质量随机化也可能跨过局部稳定界，因此名义参数相近不代表训练随机化范围安全。

PhysX内部驱动采用[隐式PD](https://nvidia-omniverse.github.io/PhysX/physx/5.1.1/docs/Articulations.html)，外部显式DC则由每步起始状态计算并保持力矩。原隐式配置能运行，不能据此推断相同数值增益直接切换到显式DC后仍稳定。

URDF各惯量正定并符合当前小腿CAD质量积分记录，未发现单位换算错误；这不等于完成实物惯性辨识。armature当前为0，真实电机/减速器等效转动惯量未辨识，不擅自指定一个值作为模型修复。

## 处理建议及当前范围

保持用户指定14/0.6、显式DC及真实模型时，应先使用已完成静态对照的1ms物理积分、20ms策略控制周期，补做宽增益/质量随机化稳定性检查，再验证新训练。既有14/0.6平地1ms结果为速度RMS0.122、加速度59.8，明显低于5ms基线。该建议不通过切换到旧摩擦或虚构惯量掩盖不稳定，也不把减少Kd的诊断值写入部署/训练。

本轮只修改诊断工具、记录数据；默认训练步长仍5ms，默认14/0.6和现有模型/摩擦未作进一步修改，未开始新训练或连接机器人。全部原始JSON、逐物理步轨迹、源码SHA及冻结诊断脚本位于outputs/TQBot2_vibration_root_cause_20261014/。质量矩阵在实际物理步更新后读取；早期actuator_ablation.json的干预后首次步前矩阵可能是旧缓存，不用其数值计算稳定界，后续free_air数据已修正读取时机。

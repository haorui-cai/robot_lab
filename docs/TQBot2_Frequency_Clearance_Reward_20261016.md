# TQBot2：2 Hz / 5 cm 奖励修订 v4

目标仍为单脚完整周期 **2.0 Hz**；摆动足底相对当地地表只惩罚 **低于5 cm** 的部分，达到或超过5 cm不惩罚。2026-10-16 本次按用户要求修订三项：站姿偏离权重 −0.2；净空不足量按5 cm归一化后用−0.5权重；步频按每只脚独立计分。两组原 rewardv3 训练已暂停于7515/7542轮，最新共同完整模型为7500；本次不自动恢复训练，也不改原冻结源码。

| 日志项 | 当前定义 | 权重 |
|---|---|---:|
| `joint_pos_penalty` | 站姿偏离L2范数；运动指令下摆动腿hip/thigh/calf全部豁免 | −0.2 |
| `feet_frequency` | 各脚真实完整周期接近2 Hz的得分，缺失周期的脚记零，固定除以4 | +0.2 |
| `feet_ground_clearance` | 摆动脚相对当地地表低于5 cm的不足量，按0.05 m归一化后平方；达到或超过5 cm时为零 | −0.5 |

旧 `feet_air_time` 和 `feet_height_body` 仍关闭。`feet_air_time_variance` 和相位协调 `feet_gait` 未修改；后者仍要求四脚周期有效。本次只去掉步频项的四脚同时有效门槛，不把相位协调的含义同时改变。独立的停止站姿项 `stand_still=-2` 保留。

## 步频：每脚独立贡献，固定分母

周期来自同一只脚相邻真实落地时间戳之差。有效周期0.08–2 s、腾空与支撑各至少20 ms、完整两相位之和必须能对上周期；旧历史超过两个周期即失效。保留漏事件检查、停止指令清空历史、复位及过期处理，不拿占位值或缺失值当达标。

```text
f_i = 1 / T_i
error_i = max(abs(f_i - 2.0), max(2.0 - 1 / elapsed_since_touchdown_i, 0))
score_i = valid_i / (1 + (error_i / 0.5)^2)
R = 0.2 * (score_1 + score_2 + score_3 + score_4) / 4
```

随后乘原有运动指令和直立系数。0/1/2/3/4只有效且达到2 Hz的脚，对应0/0.05/0.10/0.15/0.20奖励；不能因为一只无效就清零其余脚，也不能通过丢掉一只差脚的历史抬高其余脚平均分。每个控制步只计算一次，没有“落地次数越多发奖越多”的路径。未完成周期拖得过久会失分，等待不能把原先过快的周期变成新完成的合格周期。周期占空比不被本项指定。

这与v3“先平均误差再取核、四脚全有效才有奖励”不同。各脚均为相同频率时核形状不变：2/2.5/3/4 Hz原始单脚分数1/0.5/0.2/0.0588。

## 净空：只惩罚低于5 cm，保留不足区间的40倍强度

```text
h_i = dot(foot_center_world - ground_hit_world, upward_surface_normal) - 0.012
shortfall_i = max(0.05 - h_i, 0) / 0.05
C = -0.5 * sum_swing_i(shortfall_i^2 * tanh(2 * relative_tangent_speed_i))
```

显式 `error_scale=0.05 m` 独立于净空门槛，改变尺度不移动5 cm边界。系数−0.5/0.05²=−200 m⁻²，最初为−5 m⁻²，因此低于5 cm时，同状态、同门控下仍为最初强度的40倍；达到或超过5 cm时，本项为零。仅摆动脚、有效地形射线、有运动指令时参与，并乘原有直立系数。速度加权和腾空判据未修改；支撑脚仍不参加本项。

单脚净空2 cm、速度与姿态系数取1时，惩罚仍为−0.18；两脚为−0.36。净空4 cm时单脚为−0.02，5 cm、6 cm、8 cm均为零。该项逐摆动时刻评估净空不足，仍是软惩罚，不是障碍净空或摆动峰值的硬约束。足端球半径仍为1.2 cm，坡面仍用局部地形法向；降低机身本身不会假增足底净空。

历史尺度依据（改为单侧惩罚前）：7500轮回放及7401–7500轮训练日志分别重算20/40/80倍。双侧40倍下，训练净空项均值由−0.03597/−0.03728变为−1.43883/−1.49115，与线速度跟踪均值1.37669/1.61780相近；同时站姿项从−0.00906/−0.00837变为−0.18130/−0.16737。80倍会吃掉约一半正奖励量，40倍作为初始尺度。本次保留低于5 cm部分的尺度，并取消高于5 cm部分的成本，不能再把上述双侧均值当成当前单侧均值。历史重计分不能当作续训成功证据；奖励均值也不是PPO梯度贡献。

回放存在较大负净空射线结果，不能直接当作物理穿地；最高1%样本贡献约10%/13%的原净空成本，没有支配均值。保留原几何定义，未为得到好看分数而裁剪误差。

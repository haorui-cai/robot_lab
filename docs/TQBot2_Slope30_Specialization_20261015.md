# TQBot2：从 model_4200 开始的 30° 坡面专项训练

用户目标：沿“开启腿间碰撞从零训练 → model_18200 → 新限位阶段 model_500 → 足端奖励修订 → model_4200”的链路继续训练，适应正常附着条件下 0.3–0.6 m/s 上下 30° 坡，并保留平地行走。用户明确要求训练沿用原复杂地形中的凸形坡和凹形坡。

## 训练配置

| 项目 | 配置 |
|---|---|
| 地形 | 原 `hf_pyramid_slope` 40%、原 `hf_pyramid_slope_inv` 40%、普通平地 20% |
| 地形几何 | 保留原 8×8 m 高度场与中心平台；10 行、10 列 |
| 难度 | 保留原距离课程，初始最大 3 级；最后一行显式使用 difficulty=1，即名义 tan(30°) |
| 目标坡面曝光 | 每种坡面约 20% 环境固定在最高行，其余沿原课程升降级 |
| 速度 | 前向 0.3–0.6 m/s；横向/偏航命令 0；随机初始航向 |
| 附着 | 足端静/动摩擦 0.7–1.0，确保动摩擦不高于静摩擦；地面为 1.0、乘积合成 |
| 奖励与接口 | 保留父模型全部生效奖励、45→12 接口、默认关节角、隐式 PD、动作尺度、大腿限位与碰撞设置 |
| 重置 | 中心平台直立开始；保留质量、质心、增益随机化与观测噪声；本阶段关闭外部推力与外力矩 |
| 失败 | 机身相对重力倾斜超过 70° 终止；原地形边界、20 s 超时保留 |
| 优化 | 固定学习率 1e-4、熵系数 0.005，1024 环境，24 步/更新，seed=42 |
| 周期 | 每 100 轮保存；每 500 轮结束训练进程，独立评估后继续下一块 |

原金字塔高度场包含中心平台、方向变化及网格离散，名义最大坡度不是整段恒定的 30° 平面。因此它适合沿用训练，但能力验收使用独立平面坡道。正式训练不使用新平面坡道。

## 固定验收

评估使用确定性策略均值，保留观测噪声及质量/质心/增益随机化。实际碰撞网格经射线核查，最大角度误差约 0.000004°。每回合 12 s，前 1 s 为零命令安定阶段。

矩阵：坡度 −30°、0°、+30° × 速度 0.3、0.45、0.6 m/s × 摩擦 0.7、0.85、1.0，共 27 个条件。每次筛查每条件 8 个独立环境，216 回合；固定筛查种子 1042。失败回合全部计入，不以快速复位后的新回合替换失败样本。

单回合合格要求同时满足：

- 持续至 12 s；没有倾倒、持续躯干触地或离开坡道。
- 沿坡速度与横向速度的合成 RMSE ≤ max(0.10 m/s, 25% 指令速度)。
- 有效前进距离 ≥ 指令速度 × 计分时长 × 75%。
- 最大侧向漂移 ≤ 0.5 m。
- 至少 95% 计分时刻，机身上方向与坡面法向夹角小于 45°，且航向误差小于 15°。

每个条件成功率均须 ≥95%。连续两次固定筛查通过后，使用 2042、3042 两个独立种子，各条件 32 回合，每批 864 回合，两批均通过才标记 `accepted`。这是当前工程验收口径，不是实机认证，也不覆盖低摩擦、横坡、急转弯或推扰。

父模型基线（216 回合）：上坡 0/72、下坡 2/72、平地 0/72 满足全部严格条件；上坡平均净进度约 −1.98 m，存在明显后滑。平地 0/72 不表示完全不能走，主要还未满足严格的速度、漂移及航向联合要求。原始逐回合记录为 `baseline/episodes.json`。

## 持续运行与复核

`status.json` 记录监督进程、当前子进程、检查点、固定评估、最佳模型和下一阶段。监督器首批预算 10000 轮；预算结束未通过、资源不足或执行异常时进入复核状态，不会冒充完成。后续应按分条件失败模式决定继续训练或修订，而不是无限追加轮数。

训练、评估进程串行运行，避免额外同时占用显存；不会停止已有 Go2 训练。磁盘可用空间低于 5 GiB 时保留模型并停止启动下一块。整个流程只在仿真中进行，未部署到 Pi 或实机。

验证包括纯数值地形/验收测试、216 环境实物理基线、原凸/凹地形短训练和完整断点恢复。实时状态以实验目录 `status.json` 为准。

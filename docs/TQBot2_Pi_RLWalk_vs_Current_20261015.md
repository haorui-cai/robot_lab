- `model_17300`：10 月 11 日开启指定腿间自碰撞、13.3 kg、零转子质量/惯量的独立从零训练检查点。10 月 12 日部署为 Pi 默认。该阶段大腿硬范围仍为 [−3.141, 6.108] rad。

## 真正不同的条件

| 项目 | Pi model_4200 的训练 | 当前 model_2500 的训练 |
|---|---|---|
| 初始化历史 | 宽限位从零训练约 18200 轮后微调 | 新的随机策略起点 |
| 大腿限位经历 | 先 [−3.141,6.108]，再 [0.60,3.20] | 起点已为 [0.60,3.20]，1500 后改为 [0.45,3.20] |
| 小腿动作/观测零位 | −1.5 rad | −1.64456 rad |
| 执行器 | ImplicitActuator | ImplicitActuator |
| 训练名义 Kp/Kd | 20/0.5 | 14/0.6 |
| 髋/大腿、小腿力矩上限 | 23.7、35.55 Nm | 21.33、31.995 Nm；1500 前为 85% |
| 关节摩擦配置 | 旧配置 friction=0.2，新动/黏摩擦未显式配置 | 新静/动摩擦 0.4/0.4 Nm，黏摩擦 0；旧摩擦由导入逻辑清零 |
| 足端接触对象 | foot 与 calf 合并，计时读取 calf | 独立 foot，计时读取 foot |
| 非足端接触惩罚 | 排除整个 calf | 仅排除 foot，calf 纳入惩罚 |
| 摆动高度 | 对地形法向的真实球面间隙目标 3 cm，归一化不足量；−0.5 | 机身坐标 foot 高度目标 −0.165 m，平方误差；−5；1500 后仅离地足 |
| 滑移项 | 地面相对足端速度，四脚平均；−0.5 | 球面接触点切向速度，支撑足求和；−0.1 |
| 步态项 | 相同计时结构，权重 0.25 | 权重 0.5 |
| 地形 | 10% 摩擦 2.5 平地；普通足端摩擦下限 0.15；初始最高等级 3 | 无专门高摩擦平地；普通足端下限 0.3；初始最高等级 5 |
| 阶梯/方块高度范围 | 5–23 / 5–20 cm | 3.5–16.1 / 3.5–14 cm |
| 微调优化 | 固定学习率 1e−4、熵 0.005 | 自适应学习率、熵 0.01 |
| 其他奖励 | 三项温和恢复成本、两项能耗代理 | 这些专用项关闭 |

两个滑移项求和/平均、门控和测量对象不同，因此不能仅根据权重说旧项强 5 倍。两种足高项的单位归一化和定义不同，也不能按权重比较强弱。旧摩擦仅凭 YAML 不能还原新旧 API 运行时全部状态，不能直接将 0.2 与 0.4 解释为物理摩擦加倍。

宽限位预训练后收紧，与从零就用窄限位，是不同的探索过程。当前初始大腿零位 0.8，原软下限 0.73，余量仅 0.07 rad；1500 后软下限才放宽到 0.6。旧策略在收紧后仍能运动，不支持“当前关节范围内机械上不可能行走”；它支持优先检验初始化和探索路径。

## 旧 Pi 执行链与当前仿真也应区分

历史提交 `e7cad7d657dbfff90ae2b71a4c4cf0658ec94e68` 的 RLWalk 为策略 50 Hz、控制器发送 500 Hz、实机 Kp/Kd=14/0.6。目标由旧参考 [hip=0, thigh=0.8, calf=−1.5] 加残差生成，随后所有关节目标按硬范围裁剪，并按速度上限逐控制拍限制变化；行走观测另有实机姿态零点补偿。500 Hz 是控制器发送频率，不代表电机内部伺服频率。

当前训练策略同为 50 Hz、物理步长 5 ms；动作目标通用裁剪为 ±100 rad，不按硬限位逐关节裁剪，也没有该部署层目标变化率处理。仿真物理关节限位和速度限制不等于目标裁剪。旧训练只明确裁剪大腿目标，和 Pi 全关节目标裁剪也有差异。

因此实机“能迈步”由旧权重、实际机构和执行链共同实现。Pi 本来也使用 14/0.6，所以不能把当前不迈步简单归因于这组增益。新旧网络虽同为 45→12，也不能不适配观测/动作零位便直接互换权重做公平比较。

## 同轮次日志：训练历史重要，但并非全部解释

取旧开启腿碰撞从零训练与当前实验相同的第 2400–2599 轮，200 条原始标量平均：

| 指标 | 旧开启碰撞从零训练 | 当前实验 |
|---|---:|---:|
| 线速度跟踪奖励 | 1.108 | 0.879 |
| 平面速度误差日志指标 | 1.177 | 1.306 |
| 非足端接触成本 | −0.0434 | −0.2267 |
| 关节限位成本 | −0.0243 | −0.0648 |
| 关节加速度成本 | −0.745 | −0.339 |
| 关节姿态偏离成本 | −0.924 | −0.570 |

旧版本在同轮次已表现出更好的跟踪，因此不应只用“旧版训练更久”解释差异。当前非足端成本约 5.2 倍，其中存在刚体分类定义改变，不能推成摔倒或接触事件增加 5.2 倍；当前加速度成本更低，也不支持继续用旧显式 PD 振荡笼统解释。

model_4200 对应 4100–4200 窗口的线速度跟踪奖励约 1.376，平面速度误差指标约 1.010。各组地形、奖励和历史不同，以上均为描述性训练日志，不是同一条件下的策略性能消融。

## 对此前判断的修正

旧 model_17300/model_4200 与当前模型前后腿转轴方向相同，且都使用相同 joint_mirror 公式/权重 −0.05，也都没有明确 Hz 步频目标，air-time 阈值均为 0.5 s。原始 model_17300 的步态项权重也已为 0.5。

因此，几何镜像先验的不匹配仍是可改进项，但不是新旧之间新增的变化，不能优先作为此次退化的差异原因。同理，“缺少步频奖励”和“短腾空负奖励”不足以单独解释为何旧策略能迈步。用户的旧实机表现是这一点的重要反证。

当前更有依据的研究顺序是：以旧可迈步策略为参照，先核对宽限位预训练到窄限位微调的学习路径，以及足端/小腿接触定义与奖励的变化，再检验控制、姿态参考和部署处理。要量化每项因果贡献，需要保持策略坐标正确映射的交叉回放和配对训练消融；本次仅完成来源与配置审计，没有运行这些新实验。

## 对比之后的配置修订（2026-10-15）

按用户要求，当前仓库的 `TQBot2StandardWalkRoughEnvCfg` 已将行走训练的名义 Kp/Kd 改为 **20/0.5**；重置时仍按原来的 0.5–2 倍随机化，即 Kp 为 10–40、Kd 为 0.25–1。修改仅作用于行走任务的执行器副本，共享机器人资产和 Pi 部署参数不随之改变。

`undesired_contacts` 现在排除 foot、calf 和 thigh，仅保留 trunk 与四个 hip 刚体的接触惩罚。物理碰撞仍然开启；步态计时、滑移等足端项继续读取独立 foot 刚体。

足高项本次未修改。旧项测量脚底球面相对附近地形的法向间隙，以 3 cm 为目标；当前项约束足端中心在机身坐标系的 z 坐标为 −16.5 cm，即位于机身原点下方 16.5 cm。这不是“脚离地 16.5 cm”：同一个机身相对位置，在机身高度、倾斜或脚下地形改变时，实际离地间隙也会改变。

以上为后续启动使用的源码配置，不改写上表所比较的历史检查点和冻结训练配置。修改时没有 TQBot2 训练进程运行。

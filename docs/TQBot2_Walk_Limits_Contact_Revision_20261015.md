# TQBot2 行走限位、滑移与摆动足高修订（2026-10-15）

本次针对 `RobotLab-Isaac-Velocity-Rough-TQBot2-StandardWalk-v0`，根据用户要求从最新检查点完整恢复 PPO，并单独记录新实验。

## 配置与计算

| 项目 | 原值 | 新值 |
|---|---|---|
| 四个大腿硬限位 / rad | [0.60, 3.20] | [0.45, 3.20] |
| 四个大腿奖励软限位 / rad | [0.73, 3.07] | [0.60, 3.07] |
| 训练力矩比例 | 85% | 90% |
| 髋/大腿力矩上限 / Nm | 20.145 | 21.330 |
| 小腿力矩上限 / Nm | 30.2175 | 31.995 |
| 滑移项，权重 −0.1 | 足端减机身的水平速度，接触历史筛选 | 支撑足球面接触点相对静止地面的切向速度 |
| 足高项，权重 −5 | 所有足端 | 仅 `current_air_time > 0` 的摆动足 |

大腿软限位使用 startup 事件显式设置，避免修改硬限位后由全局 0.9 比例产生非预期的 0.5875 下限。软上限仍为 3.07。只修改行走派生 URDF；原始描述与恢复任务未改。策略大腿零位和站立参考仍为 0.80 rad。

滑移计算对每只半径 0.012 m 的球形足端：

`v_contact = v_foot_link + omega_foot × (−radius × terrain_normal)`

投影到地形切平面后取速度模，并在支撑足上求和。接触筛选复用接触传感器 `current_contact_time > 0`，结合地面射线有效性及 2 cm 接触距离容差；保留原有直立门控。静止地面速度为零，不再减机身速度。球面纯滚动的接触点速度为零，不会误罚；沿地面拖动才产生代价。当前实现针对静态训练地形，台阶边缘的法线用足端下方地形射线近似。

足高项复用已有 ContactSensor 的腾空时间，不引入预设步态相位。目标仍为躯干坐标系 −0.165 m，运动速度与直立门控、权重均保留。Go2 未传入可选传感器筛选参数，行为不变。

## 非足端接触归因

使用旧配置冻结源码和 `model_1500.pt`，120 个环境、六类地形固定 0 级、采样策略、40 秒回放，保留训练的随机姿态重置和域随机化。以原惩罚相同的 >1 N、3 个物理步历史、直立门控统计，得到：

| 刚体类别 | 全样本惩罚贡献 | 重置 5 秒后且直立的贡献 |
|---|---:|---:|
| 小腿 calf | 87.50% | 96.41% |
| 大腿 thigh | 11.92% | 3.55% |
| 躯干 trunk | 0.58% | 0.04% |
| 髋 hip | 0.00% | 0.00% |

全样本 240000 个环境控制步；直立筛选后 156874 个。直立样本中 FR/FL/RL/RR 小腿接触时间占比分别为 5.58% / 5.09% / 4.58% / 4.12%。以上是各刚体对原惩罚的贡献，不是摔倒概率。

**主要确实来自小腿刚体，但还不能断言全是小腿杆擦地。** `calf` 的碰撞几何同时包含长 0.153 m、半径 0.008 m 的杆圆柱，以及膝关节原点半径 0.020 m 的碰撞球；本次统计未区分这两种形状。独立足端是半径 0.012 m 的球。

当前 PhysX GPU 接触过滤明确报告不支持 `/World/ground/terrain`。原始净接触传感器正常，因此按刚体归因有效，但地形专属过滤值已全部弃用。统计包含自碰撞，不能将每次事件都解释为触地。CPU 版本出现重复材质警告已中止，未使用其未完成数据。本结果来自冻结策略回放，并非线上训练群体的直接采样。
